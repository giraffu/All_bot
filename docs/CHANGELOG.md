# 变更日志 (Changelog)

本文档记录本项目的所有重要变更，采用倒序排列。

## [1.1.0] - 2026-03-21
- **作者**: AI 编程助手
- **变更原因**: 优化算力分配公平性，提升用户体验，增加合规性检查。
- **提交哈希**: (待提交)
- **变更详情**:
  - **Feature**: 新增任务结果“公开”时的违禁词（`FORBIDDEN_WORDS`）校验功能，拦截儿童相关敏感词汇。
  - **Enhancement**: 重构动态优先级算法 (`DYNAMIC_PRIORITY_RULES`)。细化“身份”和“修为”双轨制衰减规则，将“真传弟子”等高特权身份的每日衰减阈值收紧（例如：真传弟子 40次/50次/60次 衰减梯度）。
  - **Enhancement**: 在排队等待消息中，动态展示用户的专属 VIP 加速特权后缀（例如：“🚀 _已为您开启 [真传弟子 + 金丹期] 极速通道_”），让用户直观感知其身份和修为带来的加成。
  - **Documentation**: 全面更新了 `docs/` 下的各报告文档，确保架构、功能和参数说明与最新代码保持一致。

## [1.0.0] - (初始版本)
- **作者**: 核心开发团队
- **变更详情**:
  - 初始化核心 Bot 架构，包含文生图、图生图、视频生成、自定义参数等功能。
  - 引入 TON 支付与充值系统。
  - 实现双轨制积分模型（永久灵石与临时灵石）。
  - 实现基于 FastAPI 和 Vue 3 的后台 Dashboard 监控面板。
