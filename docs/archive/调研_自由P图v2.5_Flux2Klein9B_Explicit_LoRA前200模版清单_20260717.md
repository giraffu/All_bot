## 6. 建议落地批次

1. **先做非 LoRA prompt 验证**：动漫转真人、手机自拍化、衣物/风格替换、张腿/躺姿等基础模型本身可能理解的编辑指令；标记成功率，不把结果冒充 LoRA 复现。
2. **LoRA 接入后的第一批**：Image Blend、Image Repair、Realism/Detail、Anime2Real、手机摄影、体型/胸部/体毛滑杆。这些用途参数清楚，容易做前后对比和自动验收。
3. **第二批**：裸体、透明衣物、器官细节、单一体位和单一动作；需增加人脸一致性、身体结构、敏感内容审核和失败回退指标。
4. **最后处理**：多人、双重进入、Spitroast、复杂束缚和极端视角。这些对多人身份、肢体数量和空间构图要求高，不适合作为首批懒人模板。
