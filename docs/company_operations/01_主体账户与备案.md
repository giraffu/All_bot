# 公司主体、账户与备案登记簿

## 1. 主体主数据

主体详情只保存在本机 `identity.json`，包含营业执照名称、统一社会信用代码、
法定代表人、成立日期、注册资本、注册地址、经营范围和登记机关。Git 文档只维护
字段口径，避免把法定代表人和住所扩散到远端仓库。

每次使用主体信息前核对：

- 名称、统一社会信用代码和注册地址必须与营业执照逐字一致；
- 开票抬头、银行户名、支付商户主体和网站备案主办单位之间的差异有书面解释；
- 证照变更同时更新市场监管、税务、银行、支付渠道、域名/备案和合同模板；
- 营业执照原件、电子营业执照导出件和变更回执进入 `evidence/company/`，索引记录
  来源、取得时间和 SHA-256，不修改原图。

当前对外产品名称为“真境智影”，公司网站为 <https://wuhanzhenjing.cn/>；品牌名、
支付宝应用名和公司法定名称是三个字段，合同、发票和备案不得混用。

## 2. 账户登记簿

`identity.json` 只登记账号标识和角色，`credentials.json` 保存登录秘密，
`hardware-secrets.json` 保存 E 盾等实物认证信息。每个账户至少记录：

| 字段 | 含义 |
| --- | --- |
| `platform` / `environment` | 中国银行、支付宝开放平台、支付宝商家平台、微信支付、电子税务局等 |
| `account_ref` | 不含密码的内部别名；展示时只用尾号 |
| `role` | 法定代表人、经办、复核、超级管理员、开发者或只读 |
| `owner` | 实际保管/操作责任人，不使用共享匿名身份 |
| `credential_ref` | 指向本机凭据文件的字段路径，不复制值 |
| `mfa_ref` | 手机、E 盾、证书或二次验证的保管引用 |
| `recovery` | 找回渠道、开户行/平台客服和所需材料 |
| `last_verified_at` | 最近成功登录或核验时间 |
| `rotation_due_at` | 计划轮换时间；发现复用或泄露立即提前 |

现有支付宝开放平台网页应用的非秘密应用标识为 `2021006190649422`，状态和主体绑定
仍以开放平台当次页面为准。支付宝直连支付的运行时私钥/证书继续由受保护环境投影
管理，不复制到公司运营保险库；保险库只保存路径、用途、指纹和轮换元数据。

## 3. 门户与备案登记

| 类别 | 官方入口 | 本地记录 |
| --- | --- | --- |
| 国家企业信用信息公示 | <https://www.gsxt.gov.cn/> | 主体登记与年报状态 |
| 湖北电子税务局 | <https://etax.hubei.chinatax.gov.cn:8443/> | 税种、待办、申报/缴款回执 |
| 自然人电子税务局 | <https://etax.chinatax.gov.cn/> | 全员全额扣缴申报 |
| 支付宝开放平台 | <https://open.alipay.com/> | 应用、密钥指纹、产品签约和回调域名 |
| 支付宝商家平台 | <https://b.alipay.com/> | 交易、退款、账单、发票和结算 |
| 工信部备案系统 | <https://beian.miit.gov.cn/> | ICP 主体、域名、接入商和备案号 |
| 算法备案系统 | <https://beian.cac.gov.cn/> | 算法/大模型备案或登记适用性与编号 |

备案登记簿至少包含 `record_type`、主体、域名/应用、编号、主管机关、接入商、状态、
提交/通过/变更时间、线上公示位置、证据和下一次复核时间。未知项明确写 `unknown`，
不得从浏览器书签或产品配置推断“已备案”。
