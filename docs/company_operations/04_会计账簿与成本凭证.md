# 会计账簿、成本与凭证

## 1. 账套初始化与事实源

新设有限责任公司应在第一笔真实业务前确认启用月份、会计制度、纳税人类型、本位币和
期初余额。小型业务通常选择与主管机关、财务软件和后续报表一致的“小企业会计准则”，
但不能仅因界面默认值自动确认。启用月份应覆盖最早业务；设立月无交易时可以零余额，
第一笔银行验证款、股东转款或平台收款仍应从实际发生日入账。

云记账软件中的凭证、总账和报表是法定账当前事实源；本机 CSV/工作簿用于导入、勾稽
和复核，不与云账并行维护两个互相冲突的“正式总账”。期初余额一旦产生后续凭证，
更正应通过可追踪的调整凭证或受控反结账，不静默改写历史。

科目代码随软件模板变化，稳定知识只约束科目含义和余额方向。常用最小科目如下：

| 业务 | 建议科目 | 通常余额方向 |
| --- | --- | --- |
| 人民币基本户 | `银行存款—人民币基本户` | 借 |
| 支付宝可用余额 | `其他货币资金—支付宝企业账户` | 借 |
| 支付宝提现处理中 | `其他货币资金—支付宝提现在途` | 借 |
| 可退平台验证款 | `其他应收款—平台验证款` | 借 |
| 客户已付、尚未确认收入 | `预收账款` 或所选准则要求的合同负债 | 贷 |
| 股东周转款 | `其他应付款—股东借款` | 贷 |
| 小规模增值税 | `应交税费—应交增值税（小规模纳税人）` | 贷 |
| 已履约主营服务 | `主营业务收入` | 贷 |
| 支付与银行手续费 | `财务费用—手续费` | 借 |

新增下级科目前先搜索系统预置科目，避免重复创建。父级和下级在科目余额表同时出现时，
父级是汇总展示，不是第二笔余额；验证时看最末级科目、方向和全表合计。

## 2. 最小账簿

私密 `ledger/` 至少维护：

| 文件 | 关键字段 |
| --- | --- |
| `transactions.csv` | 日期、业务单、外部流水、渠道、币种、原币、人民币、收入/退款/手续费、银行流水、凭证号 |
| `expenses.csv` | 供应商、类别、业务用途、期间、币种/金额、付款人、合同、发票/receipt、审批、税务处理 |
| `tax_filings.csv` | 所属期、税种、收入/税额、状态、回执、缴款、经办/复核、证据 |
| `reconciliations.csv` | 账户/渠道、期间、账面余额、外部余额、差异、owner、结论 |
| `vendor_register.csv` | 供应商主体/国家、服务、结算币种、合同、凭证类型、续费日、税务复核 |

CSV 是运营明细，不替代符合会计制度的总账、明细账和财务报表。后续接入记账软件时
保留原 CSV 与导入批次，不能只留下软件汇总数。

## 3. 收款、履约和往来分录模式

以下为模式，不是固定凭证号或金额；实际入账以当期订单、外部流水、履约证据、发票和
所选会计制度为准。

### 支付渠道收款与手续费

客户付款、权益尚未达到会计收入确认条件：

```text
借：其他货币资金—支付宝企业账户
贷：预收账款 / 合同负债
```

渠道扣收手续费：

```text
借：财务费用—手续费
贷：其他货币资金—支付宝企业账户
```

提现发起与银行到账分两步，分别通过“支付宝提现在途”衔接；不得将提现记作第二次
收入。日汇总凭证允许合并同类交易，但附件必须能下钻到订单和渠道明细。

### 收入和暂计增值税

达到公司选定且一致执行的履约口径后，将预收转为不含税收入和账面应交增值税。对于
当前适用 1% 减征率的含税价款：

```text
不含税收入 = 含税价款 ÷ 1.01
暂计增值税 = 含税价款 - 不含税收入

借：预收账款 / 合同负债                 含税价款
贷：主营业务收入                         不含税收入
贷：应交税费—应交增值税                 暂计增值税
```

会员、点数或长期服务是否在付款、激活、期间摊销或实际消耗时履约，必须由业务合同和
一贯会计政策决定。金额变得重大时不得用“数据太细”替代收入截止测试；内部履约汇总
只能证明系统交付事实，支付宝账单仍是资金事实源。

季度达到小微免税条件后再将账面暂计增值税转入当期损益；申报表统计免税额可能按 3%
计算，不要求与账面按 1% 暂计金额机械相等，调节逻辑见税务文档。

### 验证款和股东周转款

```text
# 公司支付、平台原额退回的验证款
借：其他应收款—平台验证款
贷：银行存款

借：银行存款
贷：其他应收款—平台验证款

# 股东借给公司周转
借：银行存款
贷：其他应付款—股东借款
```

平台向公司打入且确认无需退回的极小验证款可以转入非主营损益；确认前先挂往来。股东
借款是否分次或合并偿还由真实资金安排决定，不能把它混同实缴资本、营业收入或报销。

## 4. 凭证包标准

企业所得税税前扣除凭证遵循真实性、合法性、关联性。境内增值税应税支出通常以合规
发票为主要外部凭证；境外购进货物或劳务可使用对方发票或具有发票性质的收款凭证、
相关税费缴纳凭证。依据见[国家税务总局公告 2018 年第 28 号](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5194804/content.html)。

每项成本至少组成：

1. 合同/订单/订阅页面，说明交易双方、服务期、内容和价格；
2. 发票、invoice、receipt 或平台账单原件；
3. 银行/公司卡/渠道付款证明，个人代付时附报销单和公司偿付流水；
4. 与公司经营相关的使用证据，如资源 ID、项目、设备验收或服务期；
5. 内部审批、会计科目、税务处理、汇率来源和凭证号；
6. 更正/退款/贷项通知与原凭证的双向关联。

收入汇总凭证至少组成：渠道成功交易/退款明细、业务订单与履约汇总、手续费账单、
提现/银行入账勾稽和内部汇总说明。一个月度对账 PDF 可以关联汇总凭证；同一电子档案
若被财务系统限制不能重复关联，不应上传多次伪造多份“原件”，而应保留一份原件并为
各凭证记录可追溯的档案引用。派生的一页汇总不得替代支付宝官方交易原件。

## 5. 月结与报表核对

1. 冻结当月订单、退款、渠道账单、银行流水和供应商资料，登记仍待补的原件。
2. 核对银行、支付宝可用余额、提现在途、平台验证款、股东往来、预收、税费和手续费。
3. 查看科目余额表；父级汇总行不重复相加，借贷发生额和期末余额方向合理。
4. 损益结转前检查利润表；生成结转凭证后，收入费用科目归零并转入本年利润/未分配利润。
5. 刷新资产负债表，确认“资产合计 = 负债和所有者权益合计”。不平时先处理损益未结转、
   期初余额和报表科目映射，不通过手工塞入权益科目强行平衡。
6. 导出资产负债表、利润表、科目余额表、凭证和附件，写入私密月结日志后再结账。
7. 结账后发现错误时保留原始证据，按软件支持的反结账、更正或冲销流程处理并写明原因。

月度利润只是会计结果，不等于当月应缴企业所得税；季度增值税和企业所得税在季度终了
按税法口径汇总调整、申报和归档。

## 6. 已规划成本分类

- RunPod、DMIT、DigitalOcean、Cloudflare 等境外云服务：保留境外 invoice/receipt、
  服务期、公司项目用途、付款证明和人民币折算；另行评估跨境服务的增值税扣缴、
  企业所得税/协定及外汇手续，不能仅凭信用卡记录入账。税务总局确认境外支出应索取
  发票性质收款凭证和相关税费凭证，见[官方问答](https://www.chinatax.gov.cn/chinatax/c102449/c5222168/content.html)。
- 服务器硬件：要求公司抬头发票、采购审批、验收、序列号、使用地点和保管人；预计
  使用超过 12 个月的设备先评估固定资产和折旧，不直接全部费用化。
- 注册住所电费/网费：优先让供应商合同、户名与发票能对应公司；个人家庭与公司混用
  时，只有实际业务用途、合理分摊依据、原始账单、付款和内部审批完整后再评估报销及
  税前扣除。无法证明公司承担义务或业务关联时，宁可列为待核实/不可税前扣除，不做
  虚假对公转账。

住宅费用是否可扣除取决于合同、发票、实际用途和主管机关口径；在形成固定报销政策前
向湖北 12366 或执业会计师提供真实合同与账单确认。

## 7. 档案期限

《会计档案管理办法》规定的期限是最低期限：原始/记账凭证、总账/明细账/日记账通常
30 年；月/季/半年财务报告、银行对账单、银行存款余额调节表和纳税申报表通常 10 年；
年度财务报告永久。以[财政部、国家档案局令第 79 号](https://tfs.mof.gov.cn/caizhengbuling/201512/t20151214_1613338.htm)
及其附表为准。电子档案须保持准确、完整、可用和安全，删除前履行鉴定与审批，而非按
磁盘空间直接清理。
