# LTX T2V local A/B validation workflows

These API-format graphs are generated by `scripts/build_ltx_t2v_workflows.py` and are
only for the ordered LAN acceptance matrix:

1. official dev FP8 + distilled;
2. official dev FP8 + distilled + Sulphur;
3. official dev FP8 + distilled + Ingredients;
4. official dev FP8 + distilled + Sulphur + Ingredients.

The runtime mappings use only the two production graphs under
`workers/comfy_agent/workflows/`. A passing baseline never substitutes for cases 2
and 4; both full-stack cases must produce playable MP4 files with audio.
